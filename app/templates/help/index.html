Operator quick-start

1. Set up the tournament

  1. Setup → name it (the default is fine), keep $5 / 15% / 60-30-10 unless told otherwise.
  2. Add your teams and, under each, its players (one per line, or paste a list). You can add more any time.
  3. When ready to take cash, press Open wagering.

2. Take wagers (Cashier)

  1. Find the customer (search) or add a new one (name only is fine).
  2. Search a player, set how many entries, press Add. Repeat for as many players as they want — it all goes on one order.
  3. Take the cash (change is shown), press Record payment. The screen resets for the next customer.

3. Fix a mistake

On the Cashier (recent activity) or Ledger screen, press Void and give a reason. Nothing is ever deleted — voids are logged and totals correct themselves.

4. After the race

  1. Setup → Close wagering (no more bets).
  2. Results → pick 1st/2nd/3rd for each team, check the preview, press Generate payouts. (It won't let you until wagering is closed and all three places are chosen.)
  3. Payouts → work down the list, press Mark paid for each. A person can't be paid twice. If a placed player had no bets, record what happens to that unclaimed pool.

5. Records & safety

  • Reports → printable summaries and CSV exports (final reconciliation should balance to $0.00).
  • Admin → Back up any time; restore a backup if needed. Check the last backup time on the Dashboard.

Good to know

  • The app works with no internet.
  • Your data stays on this computer and is kept when you update.
  • Clicking Portage Horse Race (top-left) always returns home.
  • An Admin PIN (Admin screen) can protect voids, results and restore. If you forget it, use the recovery code shown when you set it.
  • Grey menu items need an open tournament first.
